# App artwork

Extracted from the installed applications' official macOS icon resources, resized to 256px for this local portfolio design. Trademarks belong to their owners.

- Finder: macOS Finder.app, Finder.icns
- VS Code: Visual Studio Code.app, Code.icns
- Ghostty: Ghostty.app, Ghostty.icns
- Xcode: Xcode.app, Xcode.icns
- OrbStack: OrbStack.app, AppIcon.icns
- Codex: ChatGPT.app (com.openai.codex), app.icns
- oMLX: oMLX.app, AppIcon.icns (not currently displayed)

Technology symbols in the parent directory come from the installed simple-icons package. MLX uses a plain text tile, not an invented logo. The editor texture is a computer-use screenshot of VS Code displaying a locally authored illustrative portfolio file. No private project code, terminals, or credentials are included.
